Cyber II

Year 2 · Networking, network operations, incident response, and forensics

This year's pacing is built from last year's state Technical Skills Assessment results, standard by standard. The two biggest opportunities for growth are Network Operations (50.68% avg) and Operating Systems (58.92% avg) — both get extra room in the calendar below.

units

UNIT 1

Operating Systems

Where students lost the most ground last year. Two indicators scored in the teens/twenties — selecting the right OS feature/tool for a customer scenario (13.56%) and installing/configuring Windows networking (25.85%) — both hands-on, scenario-based skills rather than vocabulary recall.

 UNIT 2

Industry Standards, Practices & Network Theory

The OSI model itself (42.37%) and wired/wireless connection practice (44-47%) were the softest spots last year. This is foundational for the Networking unit that follows.

 UNIT 3

Networking

The largest content standard in the tested pathway. Physical security controls (89.83%) and troubleshooting security issues (75.71%) are strengths to build on; routing basics (44.63%) and Ethernet adapter/utility skills (both 54.24%) need more hands-on lab time.

 UNIT 4

Network Operations

The lowest-scoring tested standard overall. SIEM tools scored 32.2% — the single lowest indicator on the entire exam — and network monitoring tools scored 41.24%. Port/vulnerability scanning tools (83.9%) show students CAN do well here when the tool is concrete and hands-on.

 UNIT 5

Cybersecurity Lifecycle

Generally a strength — incident scope/severity (84.75%) and data protection planning (74.58%) were solid. The one soft spot is eradication response (60.17%): make sure the incident-response simulation gives students practice actually executing the eradication step.

 UNIT 6

Computer Forensics Concepts

The strongest tested standard. Web app exploits (91.53%), phishing mitigation (84.75%), and pen-testing vs. vulnerability scanning (81.36%) were all strong. The outlier: identifying cyber threat actor types scored 48.31% — a vocabulary/categorization gap a quick sorting activity could close fast.
